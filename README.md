# Everton TV Archive

## Overview
The official Everton TV Archive is a web-based video streaming service dedicated to Everton Football Club. This platform provides fans with access to match replays, highlights, interviews, training footage, and historic content from the club's rich history.

## Features

### 🎬 Video Content
- **Full Match Replays**: Watch complete matches from current and past seasons
- **Match Highlights**: Quick access to goals, key moments, and match summaries
- **Player Interviews**: Exclusive content with players and coaching staff
- **Training Sessions**: Behind-the-scenes footage from Finch Farm
- **Historic Archive**: Classic matches and memorable moments from Everton's history
- **Fan Zone**: Supporter-generated content and fan reactions

### 📺 TV Service Features
- **Live Streaming**: Real-time coverage of pre-match build-ups and press conferences
- **Upcoming Matches**: Schedule of future broadcasts
- **Browse by Category**: Organized content library for easy navigation
- **Responsive Design**: Optimized viewing experience on desktop, tablet, and mobile devices
- **Interactive UI**: Smooth animations and user-friendly interface

### 🎨 Everton Branding
- Official Everton FC colors (Royal Blue #003366)
- Club-themed design elements
- Professional and modern interface

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for optimal experience

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Wilfy1979/everton-archive.git
   cd everton-archive
   ```

2. Open the application:
   ```bash
   # Simply open index.html in your web browser
   # Or use a local server:
   python -m http.server 8000
   # Then navigate to http://localhost:8000
   ```

### Usage
1. Open `index.html` in your web browser
2. Browse through the featured content on the home page
3. Click on video cards to simulate video playback
4. Navigate using the header menu to access different sections
5. Explore categories to find specific types of content
6. Check the "Live & Upcoming" section for current broadcasts
