# everton-archive

A digital archive showcasing historic photos and memorable moments from Everton Football Club.

## Photo Gallery

View the photo gallery by opening `index.html` in your web browser.

The gallery features:
- Historic moments from Everton's rich history
- Memorable match days at Goodison Park
- Club legends and memorable victories

## Adding Photos

To add new photos to the gallery:
1. Place your photos in the `photos/` directory
2. Update `index.html` to include the new photos in the gallery grid
3. Add appropriate captions describing the photos

## Structure

- `index.html` - Main gallery page
- `style.css` - Gallery styling
- `photos/` - Directory containing all archive photos
