# Everton Archive

A comprehensive website dedicated to preserving and showcasing the rich history of Everton Football Club.

## Features

- **Club History**: Explore the founding and heritage of one of England's oldest football clubs
- **Legendary Players**: Profiles of iconic players who made their mark at Goodison Park
- **Historic Matches**: Relive memorable moments from Everton's storied past
- **Trophy Cabinet**: Complete record of all major honors won by the club
- **Responsive Design**: Optimized viewing experience on desktop, tablet, and mobile devices

## How to View

Simply open `index.html` in your web browser to view the archive.

Alternatively, you can serve it using a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (with http-server package)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive design
- `script.js` - Interactive features and animations

## About Everton FC

Everton Football Club is a professional football club based in Liverpool, England. Founded in 1878, the club has a rich history spanning over 140 years, with numerous domestic and European honors. Known as "The People's Club" and "The School of Science," Everton has been a cornerstone of English football.
